# 要件定義: アンケート管理システム

## 概要

アンケート管理システムは、アンケートの作成・配布・回答収集・結果分析を一元管理するWebアプリケーションです。管理者はアンケートを設計・公開し、回答者はブラウザから手軽に回答できます。収集した回答はリアルタイムで集計・可視化され、データに基づいた意思決定を支援します。

---

## ユーザーストーリー

### 管理者（アンケート作成者）
- As a 管理者, I want to アンケートを新規作成・編集・削除したい, so that 目的に合ったアンケートを柔軟に管理できる
- As a 管理者, I want to 複数の質問タイプ（単一選択・複数選択・テキスト・評価スケールなど）を使いたい, so that 多様な情報を効率よく収集できる
- As a 管理者, I want to アンケートの公開・非公開を制御したい, so that 適切なタイミングで回答を受け付けられる
- As a 管理者, I want to 回答期間（開始日・終了日）を設定したい, so that 期間外の回答を防止できる
- As a 管理者, I want to アンケートのURLや埋め込みコードを取得したい, so that 様々なチャネルで回答者に配布できる
- As a 管理者, I want to 収集した回答を集計・グラフで確認したい, so that 結果をすぐに把握・分析できる
- As a 管理者, I want to 回答データをCSV/Excelにエクスポートしたい, so that 外部ツールでさらに詳細な分析ができる
- As a 管理者, I want to ユーザーに役割（管理者・編集者・閲覧者）を割り当てたい, so that チームで安全にシステムを利用できる

### 回答者
- As a 回答者, I want to URLにアクセスするだけでアンケートに回答したい, so that アカウント登録なしで気軽に回答できる
- As a 回答者, I want to 回答完了後に確認メッセージを受け取りたい, so that 正常に送信されたことを確認できる

### 閲覧者（結果閲覧専用）
- As a 閲覧者, I want to アンケート結果を参照したい, so that データに基づいて意思決定できる

## 機能要件

### アンケート管理

| ID      | 要件 |
|---------|------|
| REQ-001 | 管理者はアンケートのタイトル・説明文を入力して新規アンケートを作成できること |
| REQ-002 | 管理者はアンケートを編集（タイトル・説明・質問の追加・変更・削除）できること |
| REQ-003 | 管理者はアンケートを削除できること（論理削除とし、関連回答データは保持する） |
| REQ-004 | アンケートは「下書き」「公開中」「終了」のいずれかのステータスを持つこと |
| REQ-005 | 管理者はアンケートの公開開始日時・終了日時を設定できること |
| REQ-006 | 管理者はアンケートの回答上限数を設定できること（上限到達後は自動で受付終了） |
| REQ-007 | 管理者はアンケートを複製（テンプレートとして再利用）できること |
| REQ-008 | アンケートごとに一意の公開URLが発行されること |

### 質問管理

| ID      | 要件 |
|---------|------|
| REQ-011 | 管理者は1つのアンケートに複数の質問を追加できること |
| REQ-012 | 質問はドラッグ&ドロップまたは順序入力で並べ替えができること |
| REQ-013 | 各質問に「必須回答」フラグを設定できること |
| REQ-014 | 以下の質問タイプをサポートすること: |
|         | (a) 単一選択（ラジオボタン） |
|         | (b) 複数選択（チェックボックス） |
|         | (c) 短文テキスト入力 |
|         | (d) 長文テキスト入力（テキストエリア） |
|         | (e) 評価スケール（1〜5, 1〜10 などのレーティング） |
|         | (f) 数値入力 |
|         | (g) 日付・時刻入力 |
|         | (h) ドロップダウン選択 |
| REQ-015 | 選択肢タイプの質問（単一選択・複数選択・ドロップダウン）は選択肢を自由に追加・編集・削除できること |
| REQ-016 | 質問に補足説明（ヒントテキスト）を任意で設定できること |
| REQ-017 | 条件分岐（スキップロジック）を設定できること（特定の回答によって次の質問ページを変更する） |

### 回答収集

| ID      | 要件 |
|---------|------|
| REQ-021 | 公開中のアンケートURLにアクセスした回答者は、ログイン不要でアンケートに回答できること |
| REQ-022 | 回答者がアンケートに回答し送信ボタンを押した際に、回答データが保存されること |
| REQ-023 | アンケートの終了日時が過ぎた場合または回答上限に達した場合、回答フォームは受付終了メッセージを表示すること |
| REQ-024 | 管理者の設定により、1回答者につき1回のみ回答を許可（Cookie または IPベース）できること |
| REQ-025 | 回答者は送信完了後にカスタマイズ可能なサンクスメッセージを確認できること |
| REQ-026 | 回答データは各質問・回答者・タイムスタンプとともに保存されること |

### 結果集計・可視化

| ID      | 要件 |
|---------|------|
| REQ-031 | 管理者はアンケートごとの回答一覧をリスト形式で閲覧できること |
| REQ-032 | 選択系質問（単一選択・複数選択・ドロップダウン・評価スケール）は集計グラフ（棒グラフ・円グラフ）で表示できること |
| REQ-033 | 回答数・回答率（質問ごとの回答割合）がサマリーとして表示されること |
| REQ-034 | テキスト回答は一覧表示されること |
| REQ-035 | 収集した回答データをCSV形式でエクスポートできること |
| REQ-036 | 回答データをExcel（.xlsx）形式でエクスポートできること |
| REQ-037 | 管理者は回答データを個別に削除できること |

### ユーザー管理・権限

| ID      | 要件 |
|---------|------|
| REQ-041 | システムは以下の役割を持つこと: 管理者（Admin）、編集者（Editor）、閲覧者（Viewer） |
| REQ-042 | 管理者はシステム全体の設定、ユーザー管理、全アンケートの操作が可能であること |
| REQ-043 | 編集者は割り当てられたアンケートの作成・編集・回答閲覧が可能であること（他ユーザーのアンケートは閲覧のみ） |
| REQ-044 | 閲覧者は担当アンケートの結果閲覧のみ可能であること（作成・編集・削除は不可） |
| REQ-045 | ユーザーはメールアドレスとパスワードでログインできること |
| REQ-046 | パスワードはハッシュ化して保存されること（bcrypt またはそれ以上） |
| REQ-047 | 管理者はユーザーアカウントの作成・編集・無効化ができること |
| REQ-048 | セッションタイムアウト（非アクティブ状態が一定時間続いた場合の自動ログアウト）を実装すること |

## 非機能要件

### パフォーマンス
- NFR-001: アンケート回答フォームのページロードは3秒以内であること
- NFR-002: 同時に100名が回答しても回答送信の応答時間が5秒以内であること
- NFR-003: 10,000件以上の回答データを持つアンケートの集計表示が10秒以内であること

### セキュリティ
- NFR-011: 全通信はHTTPS（TLS 1.2以上）で暗号化されること
- NFR-012: SQLインジェクション・XSS・CSRF攻撃に対する対策を講じること
- NFR-013: 認証済みユーザーのみが管理機能にアクセスできること
- NFR-014: 回答者の個人情報（IPアドレス等）は適切に管理・保護されること
- NFR-015: パスワードポリシー（8文字以上、英数字混在）を適用すること

### ユーザビリティ
- NFR-021: PCおよびスマートフォン・タブレットのレスポンシブデザインに対応すること
- NFR-022: 主要なモダンブラウザ（Chrome、Firefox、Edge、Safari の最新2バージョン）で動作すること
- NFR-023: アンケートフォームのUIはJavaScriptが無効な環境でも基本的に動作すること（プログレッシブエンハンスメント）
- NFR-024: 管理画面のUIは直感的で、技術的な専門知識なしに操作できること

### 可用性・保守性
- NFR-031: システムの稼働率は99%以上を目標とすること
- NFR-032: データベースはバックアップを定期的（日次）に取得すること
- NFR-033: エラーログを記録し、管理者が確認できること

### 国際化・ローカライズ
- NFR-041: 管理画面・回答フォームは日本語表示に対応すること
- NFR-042: 将来的な多言語対応を考慮した設計とすること

## 受け入れ基準

### AC-001: アンケートの作成
- 管理者がタイトル・説明・質問を入力してアンケートを保存すると、「下書き」ステータスで保存される
- タイトルが未入力の場合はバリデーションエラーが表示され保存されない

### AC-002: 質問タイプの追加
- 管理者がアンケートに単一選択の質問を追加し保存すると、選択肢が正しく表示される
- 必須設定の質問を未回答のまま送信しようとすると、エラーメッセージが表示されて送信がブロックされる

### AC-003: アンケートの公開
- 管理者がアンケートのステータスを「公開中」に変更すると、発行されたURLに未認証ユーザーがアクセスして回答フォームが表示される
- 終了日時を過ぎたアンケートにアクセスすると「受付終了」メッセージが表示される

### AC-004: 回答の送信
- 回答者が全必須項目に入力して送信ボタンを押すと、回答がデータベースに保存される
- 送信後にサンクスメッセージが表示される
- 1回答制限が有効な場合、同一Cookie/IPからの2回目の回答は拒否される

### AC-005: 結果の集計表示
- 回答が1件以上あるアンケートの結果ページを開くと、選択系質問の集計グラフが表示される
- 回答件数・各選択肢の割合が正確に表示される

### AC-006: データエクスポート
- 管理者が「CSVエクスポート」ボタンを押すと、全回答データを含むCSVファイルがダウンロードされる
- エクスポートされたCSVには質問名・回答内容・タイムスタンプが含まれる

### AC-007: ユーザー権限
- 閲覧者権限のユーザーがアンケート作成ページにアクセスすると403エラーまたは権限エラーメッセージが表示される
- 管理者権限のユーザーは全機能にアクセスできる

## スコープ外（今回含まない機能）

- 回答の途中保存・再開機能（アカウントなしでは安全な再開手段がないため対象外）
- メール・SMS による回答招待機能（URLの手動共有のみ対応）
- 外部認証（OAuth / SAML / LDAP 連携）
- 高度な統計分析機能（回帰分析・クロス集計など）
- 支払い・課金機能
- ネイティブモバイルアプリ（iOS / Android）
- オフライン回答機能
- アンケートテンプレートのマーケットプレイス
- A/Bテスト機能
- 多言語対応アンケートフォームの同時提供
- リアルタイムコラボレーション編集（複数人同時編集）
